# ماسح القناة السعرية الصاعدة + الارتداد من الدعم (وصفي، ليس استراتيجية ولا توصية)
المعايير ثابتة وغير مضبوطة: انحدار لوغاريتمي 90 جلسة (ميل سنوي ≥15% وR²≥0.5)، دعم = الحد السفلي (−1.5σ)، ارتداد = أدنى 3 جلسات لامس منطقة الدعم ثم إغلاق ≥1.5% فوقه وعودة داخل القناة، ≥2 لمسات سابقة، حجم ≥1.5× متوسط 20 جلسة، سيولة ADV20 ≥ 10 مليون جنيه، بدون قفزة >11.5% في 90 جلسة (نظافة بيانات).
- 2026-11-05: ارتداد مؤكد بكل الشروط = 0 سهم. القائمة الكاملة للأسهم في قناة صاعدة وسيولة عالية: channel_watchlist.csv (+png).
- دراسة أحداث استكشافية (channel_eventstudy.json): تطوير 2017–2024 بـ127 حدثًا: زيادة إجمالية عن السوق +0.39% لعشر جلسات، CI95 [−1.5%، +2.5%]؛ صافي بعد التكلفة ≈ +0.08%. لا ميزة مثبتة. 2025–2026 مكشوفة سابقًا.
