## قواعد العزل
- لا يكتب داخل `preview-v16/` أو `data/stable/` أو `scripts/stable/`.
- لا يعدل SEPA-X أو EGX Pro.
- يمكنه قراءة snapshots مستقرة فقط كمصادر Evidence.
- كل توصية تصدر في snapshot وسجل مستقلين داخل `gann-fusion-x/data/`.
- Fail closed: إذا كانت البيانات قديمة أو متعارضة أو ناقصة بصورة جوهرية، لا يصدر BUY.
