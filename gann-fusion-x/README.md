# EGX GANN FUSION X

محرك قرار وتوقيت بحثي مستقل للبورصة المصرية يجمع بين **Gann Time/Price**، الاتجاه، القوة النسبية، الزخم، السيولة، الاختراق، الجودة الأساسية، جودة الدخول، العائد/المخاطرة وحالة السوق؛ ثم يشرح النتيجة بالعربية المبسطة بدل عرض مؤشرات بلا خلاصة.

## قواعد العزل
- كل ملفات المشروع الجديد تحت `gann-fusion-x/` فقط.
- لا يكتب داخل `preview-v16/` أو `data/stable/` أو `scripts/stable/`.
- لا يعدل SEPA-X أو EGX Pro.
- EGX Pro وSEPA-X وOHLCV وFull-Market Index مصادر **Read Only**.
- كل إشارة تصدر في Snapshot وLedger مستقلين داخل `gann-fusion-x/data/`.
- **Fail Closed / الحجب الوقائي:** إذا كانت بيانات السهم قديمة أو متعارضة، لا يصدر المحرك إشارة مرتفعة الثقة.
- لا توجد أوامر تداول آلية أو تكامل وساطة.

## المصادر
- `data/history/<TICKER>.json` — OHLCV حقيقي لحساب Gann والمؤشرات.
- `data/quant/market-search-index-v13-17.json` — السوق الكامل، البحث، السيولة والمخاطر.
- `data/stable/v16-main-app-current.json` — EGX Pro، قراءة فقط ودليل مرجعي.
- `gann-fusion-x/data/sepa-x-snapshot.json` — مرآة Read-Only من SEPA-X Stable V8؛ يمكن تحديثها بالأمر `npm run sync:sepa`.

## الواجهات
- **الخلاصة / ماذا أفعل؟** — القرار البحثي المبسط وأهم الأسباب والمخاطر.
- **أفضل فرص اليوم** — فرص قصيرة الأجل بعد فلاتر التوقيت/الاختراق/السيولة.
- **أفضل فرص الأسبوع** — فرص أوسع تشمل التجميع والمراقبة.
- **رادار Gann الزمني** — الأسهم داخل نافذة زمنية نشطة.
- **رادار الاختراق** — Confirmed / Near Breakout.
- **التجميع والفرص المبكرة** — فرص الاتجاه الجيد قبل الاندفاع.
- **تجنب المطاردة / الخروج** — حالات Overheated أو الإشارة الضعيفة.
- **تحليل السوق** — Market Regime + Benchmark تحليلي داخلي واضح أنه ليس EGX30 الرسمي.
- **توافق المحركات / Consensus** — Gann + EGX Pro + SEPA-X مع احترام اختلاف الجلسات.
- **Conflict Engine / محرك التعارض** — يوضح لماذا قد تُخفض إشارة تبدو قوية ظاهريًا.
- **تفاصيل السهم** — Gann Anchor، Time Window، Square of Nine، Trend، Breakout Trigger، Volume، RSI، RS، Quality، R/R، والأسباب المبسطة.
- **قائمة المراقبة والتنبيهات** — Watchlist محفوظة محليًا + تنبيهات Browser عند تحقق شروط المراقبة أثناء استخدام التطبيق.
- **فلترة السوق المتقدمة** — Near / Forming / Extended + حد أدنى RS + R/R + Score.
- **التحقق المالي SEPA-X** — حالة التحقق والثقة وجودة الأساسيات؛ UNKNOWN لا تتحول إلى ZERO.
- **محفظة المتابعة** — سعر شراء وكمية وأداء حالي؛ متابعة فقط بلا تنفيذ تداول.
- **سجل الإشارات** — Ledger مستقل لا يعيد تسمية توصيات المحركات القديمة.
- **الاختبار التاريخي** — قواعد محافظة وتكاليف تداول ومنع Future Leakage.
- **جودة البيانات / Freshness** — تطابق الجلسة وتحذيرات التاريخ ومصدر السعر.
- **المنهجية والمصطلحات** — ترجمة وشرح المصطلحات والأوزان.

## التشغيل والتحديث
```bash
cd gann-fusion-x
npm run sync:sepa       # يقرأ SEPA-X Stable V8 ويكتب المرآة داخل Fusion X فقط
npm run build:snapshot  # يمسح السوق الكامل ويبني Snapshot مستقل
npm run refresh         # sync + build
npm run test            # Self-Test للمحرك
npm run critic          # الناقد الهدام
npm run audit:isolation # يرفض أي تغيير خارج gann-fusion-x/
npm run verify          # test + critic + isolation
```

صفحة الدخول: `gann-fusion-x/app/index-v1.html`.
