# Engine Modules

- `math.js`: حسابات عامة وRSI/ATR/SMA.
- `gann.js`: نقطة الارتكاز، الدورات الزمنية، Square of Nine.
- `indicators.js`: اتجاه، اختراق، سيولة، زخم، قوة نسبية، حالة السوق.
- `fusion.js`: الأوزان، خطة المخاطرة البحثية، تصنيف الإشارة، أسباب مبسطة، Conflict Engine.
- `legacy-adapter.js`: قراءة snapshot من EGX Pro دون كتابة.
- `sepa-adapter.js`: عقد عام لقراءة snapshot من SEPA-X عند توفره.
