# Recommendation Contract
Only BUY_CANDIDATE, WAIT_FOR_ENTRY, WATCH, REJECT and NO_TRADE are top-level states. Every issued recommendation is append-only and versioned by snapshotHash, engine/config/model/feature versions and commit hash. Outcome observation can never mutate the original recommendation.

Production recommendations are authority-separated from research output. A production recommendation may be appended only from a CERTIFIED_PRODUCTION Session Manifest and must carry a stored Baseline Authorization token whose source Phase-3 report is independently re-hashed and verified. The authorization session, exchange-calendar version and universe version must match the immutable Session Manifest. Baseline authorizations, Session Manifests and recommendation rows are append-only. Research recommendations use the explicit research append path and cannot claim a Baseline Authorization.
