# V20 Phase 6 — Sector Provenance Audit

## Objective

Introduce sector evidence without pretending that the repository's existing sector labels are production-grade classifications.

## Findings from the inherited repository

- `config/egx-sector-map.json` is explicitly a seed map and includes fallback/inference behavior in the legacy tooling.
- `data/sector-completion-report.json` is generated by a `config_map_plus_inference` engine and does not preserve per-symbol provenance showing whether a sector came from a seed map, an upstream explicit field, or name inference.
- Current market rows do not establish an authoritative sector classification registry for V20.

## V20 policy

Sector concentration is **disabled** until all of the following are formally available:
1. an authoritative sector source registered for V20;
2. per-symbol provenance;
3. no ticker/name inference in production classification;
4. an explicitly approved coverage threshold for enabling portfolio concentration limits.

The following are research context only:
- upstream explicit sector fields without authoritative provenance;
- the inherited seed map;
- the legacy mixed completion report;
- any name/ticker inference.

## Audit output

`data/v20/sector-provenance-audit.json` records:
- the 227-symbol V20 universe;
- explicit sector fields found in candidate inherited datasets;
- seed-map sector where present;
- legacy completion-report sector where present;
- conflicts between inherited sources;
- a research candidate sector/provenance when available;
- `productionSector=null` and `acceptedForProduction=false` until authoritative evidence exists.

## Guardrails

`sector-provenance-regression.cjs` fails if:
- an inferred/seed/legacy/unverified explicit sector is accepted for production;
- Stock Profiles receive a production sector without verified provenance;
- portfolio sector concentration is enabled while provenance is blocked.

This phase does not change V16 Champion selection, V17 execution governance, V19 shadow status, portfolio allocation caps, or immutable signal hashes.
