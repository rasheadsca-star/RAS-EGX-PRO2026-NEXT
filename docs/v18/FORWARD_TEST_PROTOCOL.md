# Forward test protocol

V18 enters only as `V18_SHADOW`. Each pre-outcome snapshot is immutable and hash-addressed. Entry, target, stop, horizon, costs and ambiguity policy are frozen before the next session. A session with no candidate surviving all gates is frozen as `NO_TRADE`; this is evidence, not a failure. V16/V17 ledgers remain untouched. Promotion is manual and requires explicit approval.
