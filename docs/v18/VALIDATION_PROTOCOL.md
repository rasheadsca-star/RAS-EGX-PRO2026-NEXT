# Validation protocol

The current run uses expanding-window validation with ten-session test blocks and a five-session embargo. It reports Brier score, log loss, target ECE, accuracy/coverage, cost sensitivity, regime/sector slices, and empirical-prior/simple-momentum baselines. It is still development evidence: promotion requires a genuinely unseen holdout, fresh forward cohorts, comparison on identical V16/V17 cohorts, and zero Critical/High audit findings. Any change after forward freeze creates a new version and cannot rewrite prior outcomes.
